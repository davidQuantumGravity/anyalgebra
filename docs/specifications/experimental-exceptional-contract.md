# Experimental exceptional-algebra contract

Status: implemented experimental contract, outside the stable root API.

## Named convention

All exact octonion and Albert-algebra functions use `algmul.O.v1`, basis
`(1,e1,...,e7)`, and the Fano triples already defined in
`anyalgebra.fixtures.composition`. No function silently changes to the
Bernardoni, Gürsey, split-octonion, or WDM convention.

## Coordinate types

- exact octonion: tuple of 8 `fractions.Fraction` values;
- exact Albert element: tuple of 27 `Fraction` values;
- exact operator: 27-by-27 tuple of `Fraction` rows;
- numerical group action: tuple of 27 built-in floats, created only by
  `one_parameter_action`.

Incorrect dimensions raise `ValueError`. Unsupported coefficient types raise
`TypeError`. Exact reduction rejects floating-point operators.

## Albert operations

- `octonion_multiply(a,b)` preserves the explicit input order;
- `albert_jordan_product(x,y)` evaluates `(XY+YX)/2` with binary octonion
  products and returns Albert coordinates;
- `albert_trace`, `albert_trace_form`, `albert_freudenthal_product`, and
  `albert_determinant` implement the standard invariant formulas;
- `jordan_associator(a,x,b)` returns `(a o x) o b-a o (x o b)`;
- `left_multiplication_operator(x)` returns `L_x` on the 27-coordinate space.

## F4 operations

- `f4_inner_derivation_basis()` returns the first 52 independent original
  commutators `[L_ei,L_ej]` under deterministic sparse rational elimination;
- `is_albert_derivation(D)` checks all 729 ordered basis pairs exactly;
- `operator_coordinates(D,basis)` either returns exact coordinates or raises
  when the operator is outside the span;
- `albert_derivation_dimension_certificate()` returns the matching modular
  rank and exact-nullity bounds;
- `is_trace_form_skew(D)` checks orthogonality for the Albert trace metric;
- `trace_operator_gram` and `positive_definite_ldl_pivots` provide an exact
  positive-definiteness certificate.

The 52-dimensional result applies to the real division Albert algebra in the
named convention. The classification-theorem step identifying this compact
derivation algebra as `f4` is source-backed mathematical context, not an
outcome generated by unit tests alone.

## Group-action boundary

`one_parameter_action(D,x,t,terms=N)` applies `exp(tD)x` numerically in the
associative real-linear operator algebra. The parameter interval is cut into
substeps on which the Taylor series converges without cancellation, and `N`
bounds the series length of one substep; a substep that cannot reach
double-precision accuracy raises `ArithmeticError`. The function requires a
built-in float parameter and returns floats. It does not certify global
parameter ranges, surjectivity, or group topology.

## Degree-two and degree-three magic-square catalogue

`anyalgebra.experimental.magic_square` registers the real division and split
composition algebras under the keys `R`, `C`, `Cs`, `H`, `Hs`, `O`, and `Os`.
Each entry records the raw `A tensor J_n(B)` carrier dimension separately from
the associated Lie-algebra dimension.

For `n = 2`, the implemented construction is the standard orthogonal square

`so(Im(A) + J2(B)_0) = so(A + B)`.

The code returns the exact signature `so(p,q)`, a `Spin(p,q)` group label, and
the decomposition into `so(Im(A))`, `so(J2(B)_0)`, and the mixed sector. It can
also construct the standard integer plane generators and check their metric
skewness and commutator closure exactly.

For `n = 3`, the module catalogues the compact, half-split, and doubly split
Freudenthal--Tits real forms. Each entry records the source table and states
that its group label leaves the connected global form unspecified. The
decomposition dimensions use

`Der(A) + Der(J3(B)) + Im(A) tensor J3(B)_0`.

The symmetric companion API `n3_triality_decomposition(A,B)` returns

`dim Tri(A), dim Tri(B), 3 dim(A tensor B)`.

`triality_dimension()` supports every division and split catalogue key. The
49 exact dimension checks show that this symmetric triality decomposition and
the asymmetric Tits decomposition agree in total dimension. For `(O,O)` it
returns `(28,28,192)`, making the 56-dimensional typed diagonal completion
explicit.

The 49 labels are checked entry-by-entry against Cacciatori--Cerchiai--Marrani
(2012), Tables 1--3. This remains source-backed metadata, not an implementation
of the listed brackets.

## Legacy nested-action boundary

- `nested_left_action((a1,...,an),x,mul)` means
  `a1*(a2*(...*(an*x)))`;
- `nested_right_action((a1,...,an),x,mul)` means
  `(((x*an)*...)*a2)*a1`;
- `nested_difference_action` is the negative sum of those actions.

These three functions reproduce `NestMul`, `NestMulR`, and `NestMulD` ordering.

## Nonclaims

This contract does not establish:

- correctness of AlgMul's `O x O` tensor path;
- a global Euler parameterization of F4;
- an independently generated Chevalley-basis intertwiner;
- scientific equivalence to saved Mathematica notebook outputs;
- any bracket for the degree-three magic-square entries, which are catalogued
  labels only.
