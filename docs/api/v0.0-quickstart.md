# AnyAlgebra v0.0 quickstart

AnyAlgebra v0.0 is a neutral, exact foundation for finite structures and
evidence-bearing calculations. The package root exposes only `__version__`.
Import the scoped APIs from the modules below. These names describe the current
v0.0 implementation surface, not specialized algebra-family constructors.

## Exact parents and explicit coercion

Coefficients have exact parents. Build basis data over one declared parent and
state every conversion route. A graph may apply an exact, lossless route; it
does not choose an ambiguous or lossy route.

```python
from anyalgebra.core.coercions import CoercionGraph, CoercionMap, coerce
from anyalgebra.core.domains import QQ, ZZ
from anyalgebra.core.modules import Basis, FreeModule


def zz_to_qq(value):
    return QQ().element(value.value)


graph = CoercionGraph().with_map(
    CoercionMap(
        "quickstart.zz-to-qq",
        ZZ(),
        QQ(),
        zz_to_qq,
        injective=True,
        exact=True,
        lossless=True,
    )
)
module = FreeModule(QQ(), Basis(("e0", "e1"), coefficient_domain=QQ()))
element = module.element({0: 2, 1: (1, 2)})
assert coerce(ZZ().element(2), QQ(), graph=graph) == QQ().element(2)
assert element.parent is module
```

## Partial operations keep undefinedness visible

`Undefined` is a mathematical result, not an exception. `Indeterminate` records
a bounded or assumption-dependent nondecision, and `Failed` records a meaningful
execution failure. `totalize` is an explicit conversion to a new total operation
with a declared bottom value.

```python
from anyalgebra.core.parents import FiniteCarrier, Sort
from anyalgebra.structures.operations import PartialOperation
from anyalgebra.structures.outcomes import Defined, Undefined
from anyalgebra.structures.partiality import totalize
from anyalgebra.structures.signatures import OperationSymbol

sort = Sort("letter")
carrier = FiniteCarrier(("a", "b"), sort=sort)
symbol = OperationSymbol("product", (sort, sort), sort)
missing = object()
operation = PartialOperation.from_table(
    symbol,
    ((sort, carrier),),
    ((("a", "a"), "a"), (("a", "b"), missing)),
    undefined_marker=missing,
)
assert operation.apply("a", "a") == Defined("a")
assert isinstance(operation.apply("a", "b"), Undefined)
assert totalize(operation, bottom="bottom").operation.apply("a", "b") == Defined(
    "bottom"
)
```

## Presentations, records, and the reference backend

Presentation conversions always name their source and target kinds. A conversion
plan retains its route and can reject ambiguity. Stable records use an in-memory
allow-list registry, so unknown type tags are rejected. The bundled reference
backend is exact. Optional adapters are separate and must report their
capabilities; their presence is never required for these examples.

```python
from anyalgebra.backends.reference import ReferenceBackend
from anyalgebra.persistence.registry import SchemaError, SerializerRegistry

capabilities = ReferenceBackend().capabilities()
assert capabilities.name == "reference"
try:
    SerializerRegistry().from_record({"schemaType": "unknown", "schemaVersion": 1})
except SchemaError as error:
    assert error.code == "unknown_schema_type"
else:
    raise AssertionError("unknown serialized tags must be rejected")
```

## Evidence and limits

Use `CalculationContract.create`, `run_calculation`, and `verify_replay` to keep
inputs, bounds, backend identity, artifacts, and replay status separate from a
claim. A negative result and an inconclusive result are durable outcomes. A
passing finite grid establishes only its declared grid or a separately stated
basis-reduction theorem; it does not establish an unrestricted statement.

The composition fixtures, operator dossier, and replay dossier provide the
larger executable release examples. They retain exact coefficient parents,
explicit conversion routes, partiality, nonclosure witnesses, bounds, and
replay state. They are infrastructure evidence only. v0.0 does not provide
specialized composition, Clifford, Lie, Jordan, or scientific-analysis APIs.
The optional Wolfram adapter runs a bounded fresh-process audit and is not an
AlgMul correctness oracle.
